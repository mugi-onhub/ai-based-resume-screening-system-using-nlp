Entry‑Level AI / Data Science Associate (MNC)

Develop baseline machine‑learning models such as linear regression, logistic regression, decision trees, and K‑nearest neighbors with Scikit‑learn.

Record model performance metrics (accuracy, F‑score, MAE, RMSE) and present findings in weekly team meetings.
Write clean, documented Python scripts, use Git for version control, and participate in code reviews.

Bachelor’s degree in Computer Science, Statistics, Mathematics, or a related field (average GPA ≥ 3.0).
Proficiency in Python (≥ 3.8) and comfortable with Jupyter notebooks.
Basic understanding of supervised/unsupervised machine‑learning concepts and evaluation metrics.
Experience with Pandas, NumPy, and handling CSV/JSON/Excel files.
Ability to create visualisations with Matplotlib, Seaborn, or Plotly.
Familiarity with tokenisation and pre‑trained embeddings for NLP.
Basic Git workflow knowledge.
Good analytical thinking, clear written communication, and eagerness to learn.
Nice‑to‑have

Exposure to cloud services (AWS, GCP) and Docker.
Introductory experience with PyTorch or TensorFlow.
